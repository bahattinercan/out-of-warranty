# Out of Warranty

Out of Warranty is a modern browser-based 2D turn-based tactical artillery game where service robots clash for scrap and spare parts in an abandoned megafactory. It features fully destructible terrain, dynamic crosswind physics, 34 unique robot models, modular equipment and workshop progression, and a serverless WebRTC peer-to-peer (P2P) multiplayer infrastructure.

### Overview

**Out of Warranty** is a browser-based 2D tactical artillery game where maintenance robots clash for spare parts in a desolate industrial megafactory. It features fully destructible terrain, procedural audio, 34 playable robots with unique tactical modules, and serverless WebRTC peer-to-peer multiplayer with zero external dependencies.
